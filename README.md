## 🏨 SleepWell

> Aplicativo desenvolvido para facilitar e agilizar o gerenciamento de reservas e serviços de hotel. Ele possui uma integração com uma aplicação Web (Aqui está o link do repositório: https://github.com/aclaramarques/sistema-gerenciamento-hotel), que é voltada especificamente para os administradores e funcionários, enquanto a parte web é para uso dos clientes, nela podem ser realizadas as seguintes ações:
> - Se cadastrar no app, fazerlogin, editar perfil e fazer logout;
> - Visualizar quartos;
> - Fazer reservas, ver e excluir;
> - Mudar algumas configurações no app (ex.: idioma);

## Instruções de uso
* Clonar o projeto;
* Verificar e instalar dependências do Flutter;
* Conecte um dispositivo (celular físico) ou inicie um emulador (pelo Android Studio ou VS Code);
* Verifique os dispositivos ativos com o comando: flutter devices
* Rode o aplicativo com: flutter run
* Cadastre-se no app.
